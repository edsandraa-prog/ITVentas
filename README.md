# ITVentas – Sistema de Compras y Ventas

## Descripción del proyecto

ITVentas es una aplicación web desarrollada para facilitar la administración de un negocio mediante el control de artículos, categorías, proveedores, clientes, usuarios, compras y ventas.

El sistema permite organizar la información y mantener actualizado el stock de los productos.

## Objetivo

Desarrollar un sistema web que permita gestionar de manera ordenada las operaciones de compras, ventas e inventario, facilitando el control de los productos y la consulta de información.

## Tecnologías utilizadas

- PHP: desarrollo de la lógica del sistema.
- MySQL: almacenamiento de información.
- HTML5: estructura de las páginas.
- CSS3: estilos de la interfaz.
- Bootstrap: diseño adaptable.
- AdminLTE: plantilla de administración.
- JavaScript: funcionalidades dinámicas.
- jQuery: manipulación del DOM y eventos.
- AJAX y Fetch API: intercambio de información sin recargar la página.
- DataTables: organización y búsqueda de datos en tablas.

## Módulos del sistema

1. **Artículos:** registro y administración de productos.
2. **Categorías:** clasificación de los artículos.
3. **Proveedores:** registro de proveedores.
4. **Clientes:** administración de clientes.
5. **Usuarios:** gestión de cuentas y accesos.
6. **Compras:** registro de compras y actualización del stock.
7. **Ventas:** registro de ventas y descuento del stock.
8. **Consultas:** revisión de compras y ventas por fechas.

## Arquitectura del proyecto

El proyecto utiliza una organización basada parcialmente en el patrón MVC (Modelo-Vista-Controlador).

- **Modelos:** contienen operaciones relacionadas con los datos.
- **Vistas:** muestran las interfaces del sistema.
- **AJAX:** procesa solicitudes entre la interfaz y el servidor.
- **Configuración:** contiene los parámetros de conexión a la base de datos.

## Requisitos para ejecutar el proyecto

- XAMPP.
- Servidor Apache.
- Base de datos MySQL.
- Navegador web.
- Editor de código Visual Studio Code.

## Instalación

1. Copiar la carpeta del proyecto dentro de `htdocs` de XAMPP.
2. Iniciar Apache y MySQL.
3. Crear la base de datos en phpMyAdmin.
4. Importar el archivo SQL incluido en la carpeta `database`.
5. Revisar la configuración de conexión a la base de datos.
6. Abrir el proyecto desde el navegador.
